T-1968 and T-1994. Bounded virtio ext4 and overlay writes inside an amd64 guest.

Build a small initramfs with static BusyBox, an /init shell script, and
modules from the verified Alpine 3.22.6 amd64 modloop of pod-services
v0.84.0. Mount devtmpfs, proc and sysfs in the guest. Load crc32c_generic,
virtio_blk, crc16, mbcache, jbd2, ext4 and overlay in that order. Create a
64 MiB raw file and format it with mke2fs 1.47.2 using these options.
  mke2fs -q -F -t ext4 -b 4096 -m 0 -E lazy_itable_init=0,lazy_journal_init=0 disk.raw

The init mounts ext4 with nodelalloc on /disk, mounts overlay at /merged
with lowerdir=/lower,upperdir=/disk/upper,workdir=/disk/work, and reads a
file from lower. Overwrite that file through /merged and compare all
three copies. Write 4 MiB and then 96 MiB to separate files in /merged.
After reboot, debugfs reads the copied-up and 4 MiB files from the disk.

A separate direct ext4 control confirmed that the disk enumerated with
131072 sectors. A 4 MiB write succeeded and a 96 MiB write stopped at
52985856 bytes with No space left on device and exit 1. Omitting only
crc32c_generic still enumerated the disk, but the mount reported
EXT4-fs (vda): Cannot load crc32c driver.
