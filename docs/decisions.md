date of each, the calls made without a ruling, and the questions for the
owner. A ruling stays in force until a later ruling supersedes it. Then
move it to the table "Superseded", with the ruling that replaced it.
`TODO/RULES.md`, section 11, has the standing decisions of 2026-10-02 and
before; they stay in force where no row here supersedes them.
`AGENTS.md` has the short form of the rulings that apply to each session.

## Questions for the owner

Q10 (2026-11-20, T-2008, call C27): the machine tier now saves the state
of a guest that booted the init of an image, by default, and each later
run starts from it: the first output comes about 12 times sooner under
TCG (1.5 s against 19 s), at a cost of about 1.5 GiB of the store for
each image and guest shape. Each run of one state shares the machine-id,
the boot id, the monotonic clock and each secret that a service made at
its start (a host key of SSH, a cookie of a database). The
recommendation: keep the save as the default, with `PODVM_MACHINE_STATE=0`
as the off switch, because the machine tier is the last route of call
C26 and its users want the start; name the shared identity in the help
and in the report of the run. Until the owner answers, the save stays the
default and the help names the off switch.

Q9 (2026-11-15, T-1876): the Windows catalog pins URLs, sizes and
digests in the binary, so a moved URL needs a release. The weekly job
`catalog-drift.yml` finds a drift and opens an issue. The
recommendation: keep the pins in the binary (each pin is checked by its
sha256), and answer a drift with a patch release; a catalog that the
binary fetches at run time needs a signature and a key, which podvm does
not have. Until the owner answers, a drift is a patch release.

Q8 (2026-11-15, T-1824): a run is quiet by default, and only
`--verbose` prints the banner; the problem of T-1824 asks for a line on
the default path. The recommendation: print one line on stderr by default only where the
entered rung gives no isolation (chroot, userland, supervise) and stdout
or stderr is a terminal; `-q` and a pipe stay silent. Until the owner
answers, the default stays quiet, and each text says "with `--verbose`".
